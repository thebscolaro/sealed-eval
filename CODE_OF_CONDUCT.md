# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language
- Being respectful of differing viewpoints
- Accepting constructive criticism gracefully
- Focusing on what is best for the community

Examples of unacceptable behavior:

- Harassment, trolling, or insulting comments
- Publishing others' private information
- Sharing seal tokens or sealed hold-out corpora from private deployments

## Enforcement

Report issues to the maintainers via GitHub Security Advisories or a private maintainer contact listed in `SECURITY.md`. Maintainers will review and respond as they can.
